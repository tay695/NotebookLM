Sistemas embarcados — Pesquisa para o TCC
Objetivo
Este repositório tem como objetivo organizar os estudos e as fontes de pesquisa relacionados ao Trabalho de Conclusão de Curso (TCC) em desenvolvimento, com foco em sistemas embarcados. O material reúne uma base de consulta para apoiar a compreensão dos conceitos e das características técnicas envolvidos no projeto.
Fontes utilizadas
As fontes de pesquisa são monografias, livros e datasheets (folhas de dados técnicos), fornecidos em formato PDF e adicionados ao NotebookLM.
Regra de utilização das fontes
A regra da atividade é utilizar exclusivamente os PDFs fornecidos. As perguntas, respostas e sínteses devem se apoiar nesses documentos, sem acrescentar informações de sites ou de outras fontes externas.

Cada resposta reproduzida neste README deve indicar o documento de origem e, sempre que possível, a página ou a seção correspondente. Quando uma informação não estiver nos PDFs, essa ausência deve ser informada, sem completar a resposta com conteúdo externo.
